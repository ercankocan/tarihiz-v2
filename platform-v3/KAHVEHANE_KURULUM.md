OSMANLI’DA KAHVEHANE HAYATI — MEVCUT PLATFORMA EKLEME

HTML değişmez. Göbeklitepe ile kullandığınız TarihIz_Pilot.html dosyasını kullanmaya devam edin.

1. ZIP içindeki pilot-gorseller klasörünü Tarihİz klasörüne çıkarın ve mevcut pilot-gorseller ile birleştirin. Ek bir kahvehane klasörü açmayın.
Doğru yol: Tarihİz/pilot-gorseller/osmanli-kahvehane/kaynak.jpg
2. tarihiz-sade-test projesinde SQL Editor → New query açın. kahvehane.sql dosyasının tüm içeriğini yapıştırıp Run düğmesine basın.
3. Localhost sayfasını Ctrl+F5 ile yenileyin ve mevcut katılım kodunuzla giriş yapın. Yeni konu listede görünecektir. Önceki çalışmalar korunur.
Görsel kontrolü: http://localhost:8000/pilot-gorseller/osmanli-kahvehane/kaynak.jpg
